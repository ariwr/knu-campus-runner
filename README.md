# 프로젝트 이름 : <A+ Escape: IT4호관 탈출> (가제)

## 1. 프로젝트 한 문장 설명

경북대학교 IT4호관을 배경으로, 컴퓨팅 사고와 SW코딩 과목에서 A+를 받기 위해 Python 개념 아이템을 모으고 건물을 탈출하는 pygame 기반 2D 탈출 게임입니다.

---

## 2. 프로젝트를 만들려는 이유

처음에는 학교 건물을 배경으로 한 3D 게임을 만들고 싶었지만, 프로젝트 기간과 Python 기초 문법 수준을 고려했을 때 3D 맵과 카메라를 구현하는 것은 어렵다고 판단했습니다. 그래서 실제 구현 가능성을 높이기 위해 pygame을 활용한 2D 탈출 게임으로 범위를 조정했습니다.

이 프로젝트는 단순한 탈출 게임이 아니라, 현재 수강 중인 컴퓨팅 사고와 SW코딩 과목의 학습 과정을 게임 목표로 표현합니다. 플레이어는 IT4호관 안에 갇힌 학생이 되어 변수, 조건문, 반복문, 함수, 리스트, 딕셔너리와 같은 Python 개념 아이템을 모아야 합니다. 모든 필수 아이템을 모으면 A+ 조건을 만족하게 되고, 최종적으로 IT4호관을 탈출할 수 있습니다.

이를 통해 수업에서 배운 Python 기초 문법을 문제 풀이에만 사용하는 것이 아니라, 하나의 동작하는 게임 소프트웨어로 연결해보고자 합니다.

---

## 3. 예상 사용자

- 컴퓨팅 사고와 SW코딩 과목을 수강하는 학생
- Python 기초 문법을 게임 형태로 복습하고 싶은 학생
- 경북대학교 IT4호관이라는 학교 배경에 공감할 수 있는 학생
- 간단한 2D 탈출 게임을 즐기고 싶은 사용자

---

## 4. 결과물 형태

pygame을 활용한 2D GUI 게임입니다.

사용자는 방향키로 캐릭터를 이동시키며 IT4호관 내부를 탐색하고, Python 개념 아이템을 수집한 뒤 출구에 도착해 탈출을 시도합니다.

---

## 5. 핵심 기능 3가지

### 기능 1. IT4호관 내부 탐색 기능

사용자는 방향키를 이용해 플레이어 캐릭터를 상하좌우로 이동시킬 수 있습니다.  
게임 화면은 실제 IT4호관 전체를 정교하게 재현하기보다는, 강의실, 복도, 출구가 있는 간단한 2D 맵으로 표현합니다.

사용할 Python 개념:

- 변수
- 연산자
- 조건문
- 반복문
- pygame 키보드 입력 처리
- 좌표 계산

---

### 기능 2. Python 개념 아이템 수집 기능

맵 곳곳에는 컴퓨팅 사고와 SW코딩 과목에서 배우는 Python 개념 아이템이 배치됩니다.  
플레이어가 아이템에 닿으면 해당 아이템을 획득하고, 획득한 아이템 개수가 증가합니다.

아이템 예시:

- 변수 노트
- 조건문 카드
- 반복문 배지
- 함수 열쇠
- 리스트 조각
- 딕셔너리 지도

사용할 Python 개념:

- 리스트
- 딕셔너리
- 조건문
- 반복문
- 문자열
- 충돌 판정

---

### 기능 3. A+ 판정 및 탈출 기능

플레이어가 출구에 도착했을 때, 모든 필수 아이템을 모았는지 확인합니다.  
아이템을 모두 모았다면 A+를 획득하고 탈출에 성공합니다.  
아이템이 부족하다면 “아직 A+를 받을 수 없습니다. Python 개념 아이템을 더 모으세요!”라는 메시지를 출력합니다.

사용할 Python 개념:

- 조건문
- 함수
- 리스트 길이 확인
- 게임 상태 관리
- 문자열 출력

---

## 6. 사용할 Python 개념

이 프로젝트에서는 다음 Python 개념을 사용할 예정입니다.

- 변수: 플레이어 위치, 아이템 개수, 게임 상태 저장
- 연산자: 좌표 이동, 아이템 개수 계산
- 조건문: 아이템 획득 여부, 탈출 가능 여부 판단
- 반복문: 게임 화면을 계속 갱신하고 이벤트 처리
- 함수: 이동, 아이템 충돌 확인, 화면 출력, 탈출 판정 기능 분리
- 리스트: 여러 아이템과 획득한 아이템 목록 관리
- 딕셔너리: 아이템 이름, 위치, 크기, 획득 여부 저장
- 문자열: 아이템 이름과 안내 메시지 출력
- random 모듈: 아이템 위치를 무작위로 배치할 때 사용
- pygame 라이브러리: 게임 창, 그래픽 출력, 키보드 입력, 충돌 판정 처리

```

player = {

}
```
